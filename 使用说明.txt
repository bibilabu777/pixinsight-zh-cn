PixInsight 中文（外挂式简体中文汉化） 使用说明
版本：1.3.2（2026-11-24）　词典：25,911 条　适配：PixInsight 1.9.6 / Windows Qt6 x64
项目主页：https://github.com/bibilabu777/pixinsight-zh-cn
测试状态：目前仅在 1.9.6 与 1.9.5（Windows Qt6 x64）实测通过；其他版本请自行测试。
====================================================================


一、怎么用（一分钟）
--------------------
安装后桌面会出现「PixInsight 中文」快捷方式，双击即可。

中文界面：双击桌面「PixInsight 中文」
          或运行   <PI根目录>\zh_cn\pi_zh_loader.exe

英文原版：直接运行原版 <PI根目录>\bin\PixInsight.exe

（<PI根目录> 指 PixInsight 的安装目录，即包含 bin\PixInsight.exe 的那一层。）

汉化只在进程运行时生效，退出程序即恢复原状。
原始 PixInsight.exe 与所有模块 DLL 均未被修改，
官方升级、文件校验、重装都不受影响。


二、启动参数
------------
--root <目录>  指定 PixInsight 安装目录（也可用环境变量 PI_ZH_ROOT）
--no-doc       不切换 PJSR 帮助文档语言
--no-wf        不自动加载 zh_cn\workflow.xpsm
--help         显示帮助
其余参数       原样透传给 PixInsight

默认按 zh_cn 的上一级目录推导 PI 根目录；同一台机器装多个 PI 版本时，
各版本根目录下各放一份 zh_cn 即可，互不干扰，无需重新编译。

多开与残留：
· 程序已在运行时再次双击，不会重复开窗口，而是把已有窗口切到前台。
· 正在启动中（无窗口、运行不足 150 秒）不会被误杀，启动器会等待。
· 上次异常退出留下的无窗口残留进程（超过 150 秒）会被自动清理后重启。


三、文件构成（<PI根目录>\zh_cn\）
--------------------------------
pi_zh_loader.exe   启动器：启动 PixInsight 并注入汉化模块
pi_zh.dll          汉化模块：运行时替换界面文本
zh_cn.tsv          外置词典：英文原文 <TAB> 中文译文（25,911 条，约 5.15 MB）
pi_zh.log          运行日志（注入结果、词典加载条数、自检）
loader.log         启动日志（进程、注入、工作流）
使用说明.txt       本文件
*.bak-*            历次改动前的自动备份，可保留也可删除


四、原理与安全边界
------------------
启动器以挂起方式创建 PixInsight 进程，把 pi_zh.dll 注入进去；
DLL 挂钩 Qt6 的文本显示接口，在绘制/赋值瞬间把英文换成中文。

安全边界：
· 只改内存里显示的字，不改磁盘上的程序文件。
· 不涉及授权、序列号、激活、试用或任何形式的破解——只做显示层翻译。
· 本包不包含、不链接、不分发 PixInsight 本体、安装包、官方 DLL 或官方文档。
· 唯一在 zh_cn 之外的动作：帮助文档 doc\docs\PJSR\PJSR.html 的
  语言切换（官方原文保存为 PJSR.html.en，汉化版为 .zh）。
  仅当安装目录里自备了 PJSR.html.zh 才会发生，本包不附带该文件；
  不需要可用 --no-doc 关闭。

使用前提：请确认你拥有合法的 PixInsight 授权；本项目面向正版用户，
界面翻译仅为本地化便利，请同时遵守 PixInsight 的最终用户许可协议。

六、仍然保留英文的地方（正常现象）
----------------------------------
1. 进程控制台的运行日志与报错——程序输出，不是界面文字。
2. 磁盘上真实的文件名、文件夹名、路径、盘符——翻译会与实际路径不一致。
3. 作者名、网址、版权声明、许可文本。
4. 标识符类：工作流 icon id、API/枚举标识符、格式标记（XISF/FITS）、
   设备与滤镜型号（Canon/Nikon/Askar/Astrodon）、系统字体名。
   这些改了会与程序内部标识或实际硬件不一致，故保留原样。
5. 文档浏览器正文由 QtWebEngine 内核渲染，绘制层钩子够不到；
   仅 PJSR.html 支持磁盘语言切换，且需你自备 PJSR.html.zh，
   其余官方文档仍为英文。
6. 少数按钮文本两侧带空格（如 " Auto Stretch "）。程序加载词典时会裁掉
   键首尾空白，这类字符串永远命中不了，需改进 DLL 的键裁剪逻辑后才能修。
   长说明段落若由「字面量 + 版本号 + 字面量」在运行时拼成，整串无法预知，
   同样只能保持英文。
7. 少数脚本的下拉项（如 Star Reduction 的 Strong / Moderate / Soft 与
   四个 Reduction method 选项）。这些文本会被脚本读回来当逻辑常量比较，
   译成中文等于改了程序常量，会让脚本静默失效（星点缩减不出结果）。
   本项目按规则不译；要中文且功能正常，只能改脚本改用索引取值。


七、出问题怎么查
----------------
先看 <PI根目录>\zh_cn\pi_zh.log，正常应有：

    dict loaded: 25915 entries, 0 failed, skipped_long=0
    round0 patched 42
    selftest ... hit=1

（加载数应与词典行数一致。少 1 说明有一行格式不对被跳过，
  对出来补上即可；只要 failed=0 且 skipped_long=0 就正常。）

对照排查：
· 界面全英文
  → 是否直接开了 PixInsight.exe；请改用 pi_zh_loader.exe 启动。
· 弹窗提示「汉化模块注入失败，将以英文原版启动」
  → 看 loader.log 的「注入结果=0」；多为安全软件拦截 DLL 注入，
    把 <PI根目录>\zh_cn 加入白名单后重试。
· 中文显示成方块/问号
  → zh_cn.tsv 编码被改坏了。必须是 UTF-8（带 BOM）、CRLF、
    原文与译文之间一个制表符。可从最近的 .bak-* 还原。
· 文档面板白屏
  → 启动器已设置禁用 GPU 合成；仍白屏可清理 QtWebEngine 缓存目录后重试。
· 双击没反应
  → 多半是已有实例在前台；或残留进程尚未超过 150 秒判定阈值。
· 官方升级之后
  → 汉化无需重装，照常用 loader 启动。


八、手动改词条 / 自定义
-----------------------
用 Notepad++ 或 VSCode 打开 zh_cn.tsv（5 MB 左右，系统记事本会明显卡顿）。
格式为「英文原文 <TAB> 中文译文」，一行一条：

    File	文件
    Process Console	进程控制台

注意：
· 中间的制表符不能换成空格。
· 不要在同一条里放真实换行；原文里带换行的，原文侧写 \n（两个字符）。
· 译文侧不要写 \n：程序不会把译文里的 \n 还原成换行，会显示成反斜杠加 n。
  原文分两行而译文想显示成一行，直接写单行中文即可。
· 保存为 UTF-8（带 BOM）、CRLF 换行。
· 改完重启中文版生效；想恢复某条的英文，删掉该行即可。
· 不要给「脚本会读回的下拉项」加译文（如 Strong / Moderate / Soft、
  Transfer Method 等）：脚本用 itemText() 取回文本与英文常量比较，
  译文会让比较失败、功能静默失效。用 scan_js.py --readback 可查出这类项。


九、备份、升级与卸载
--------------------
备份：整个 <PI根目录>\zh_cn 文件夹复制一份即可（含词典、程序、说明）。
升级：PixInsight 官方升级不影响本汉化；换大版本时把 zh_cn 整个复制过去即可。
卸载：删除整个 <PI根目录>\zh_cn 文件夹，再删掉桌面快捷方式即可。
      PixInsight 本体没有被改动过，删除后就是原版。
